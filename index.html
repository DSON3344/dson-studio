VisionLogic AI

Intelligent Design Evaluation Platform

RoleSolo Designer & Full-Stack Developer

The Problem

Design feedback in academic settings has always been broken. A student submits their best work, waits days for a review, and gets back something vague — "the composition feels off." Two lecturers, two different verdicts. No rubric, no consistency, no benchmark.

This directly impacts GPA: a survey of 68 participants found 53% reported that inconsistent grading had negatively affected their academic performance, and 26.5% strongly agreed a standardized, objective evaluation tool was needed.

The Concept

VisionLogic AI is a web-based intelligent design auditor — designers upload their work and receive instant, structured, AI-powered feedback scored across six professional metrics. The goal: replace subjective human critique with a consistent, data-driven framework, without sacrificing an experience that's intuitive for students at any skill level.

Upload. Analyze. Improve.

Design Process

Research & problem definition — a literature review confirmed no local tool existed for standardized design evaluation in Malaysia; a PESTLE analysis aligned the platform with Malaysia's National AI Roadmap and MyDIGITAL Phase 3 (2026–2030). Every decision was filtered through the Technology Acceptance Model (perceived usefulness + ease of use).

Wireframe to high-fidelity — from low-fidelity sketches and user-flow diagrams to a complete high-fidelity prototype in Figma, anchored in a dark-first aesthetic with cyan (#40CFC4) accents and a dual-mode sidebar (Guest / User).

  • Landing page — hero with animated CTA and interactive guide
  • Analyze dashboard — upload zone, category/tone selector, live Radar Chart
  • History page — filterable evaluation log with export
  • Account & settings — profile, language (EN/CN/MY), legal terms

The AI Evaluation Engine

Powered by Gemini AI (Flash model) via Google AI Studio, governed by a custom prompt-engineering framework: a Professional Design Director persona, 90/10 visual-to-context weighting, structured JSON output rendered as a Radar Chart plus a 2-page report — in English, Chinese, or Malay.

Each design is scored across six metrics tailored to its category — UI/UX (Usability, Hierarchy, Consistency, Accessibility, Spacing, Flow), Graphic Design (Layout, Typography, Color Harmony, Visual Hierarchy, Impact, Whitespace), or Photography (Exposure, Color Mood, Texture, Balance, Contrast, Detail).

Technical Architecture

Built on Node.js + Express — chosen over React mid-development for reliable server-side Gemini API key management. MongoDB handles auth, sessions, and evaluation history under PDPA 2010 compliance; Vercel was selected over GitHub Pages for Node.js runtime support.

  • Multer — design image upload handling
  • Bcrypt + Express-Session — password hashing & session management
  • Nodemailer — OTP authentication emails
  • Puppeteer — automated PDF report generation

Challenges & Solutions

React pivot mid-development — client-side rendering couldn't securely manage the Gemini API key, so the frontend was rebuilt in vanilla HTML/CSS/JS on an Express backend. Costly in time, correct in direction.

Gemini prompt calibration — early evaluations were inconsistent until a structured prompt system with fixed personas and enforced JSON output made the AI behave like a design director, not a generalist chatbot.

Hosting limitations — GitHub Pages doesn't support Node.js execution, so Vercel was chosen for its runtime and secure environment variables.

13-week deadline — delivered April 26, 2026, covering research, design, full-stack development, testing, deployment, and thesis submission in parallel.
